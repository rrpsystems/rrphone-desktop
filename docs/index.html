Softphone SIP para Windows. Leve, direto ao ponto, código aberto.

Baixar para Windows
Windows 10/11 · 64-bit · ver todas as versões
O instalador cuida do runtime necessário automaticamente.

Recursos

  • Transferência com consulta, num fluxo só
  • Chamada em espera (atender, recusar, alternar)
  • G.729 e G.711, sem custo de transcodificação no PBX
  • Não perturbe e encaminhamento incondicional (siga-me)
  • Microfone, alto-falante e toque roteados separadamente
  • Histórico local e agenda via XML remoto (formato MicroSip)
  • Provisionamento por arquivo, criptografado (AES-256-GCM)
  • Cancelamento de eco e supressão de ruído opcionais

Instalação

O instalador ainda não é assinado digitalmente, então o Windows pode mostrar "O Windows protegeu o computador" ao abri-lo. Isso é esperado: clique em Mais informações e depois em Executar assim mesmo.
